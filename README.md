# 🌍 World Happiness Analysis (Focus on Poland)

## 📌 Project Overview

This project explores global happiness data with a particular focus on **Poland**.
The goal is to analyze how happiness levels have changed over time, identify factors that may influence happiness, and compare Poland with other countries in Europe.

The analysis is based on the **World Happiness dataset** and is implemented using **Python in Jupyter Notebooks**.

The project is divided into two main analytical sections:

1. **Poland-focused happiness analysis** - poland_happiness.ipynb
2. **Global happiness trends analysis** - world_happiness.ipynb

---

# 📊 Analysis Structure

## 1️⃣ Happiness Analysis in Poland

This section investigates how happiness levels in Poland have evolved over time and how they compare with other countries.

Key analyses include:

* Happiness trends in **Poland over the years**
* Poland’s **ranking compared to other countries**
* **Correlation analysis** between happiness score and other variables
* Relationship between **social support and happiness**
* Comparison of Poland’s happiness score with **other European countries in 2012 and 2024**

---

## 2️⃣ Global Happiness Analysis

The second section focuses on worldwide happiness trends and patterns.

Key analyses include:

* Global **average happiness score over time**
* **Correlation analysis** between happiness and other socio-economic variables
* Identification of:

  * 🌟 **Top 10 happiest countries (2024)**
  * 📉 **Top 10 least happy countries (2024)**
